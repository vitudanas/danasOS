# danasOS • Noite em Neon

Distribuição Linux para jogos com base no Debian 13 e no Xfce. O projeto inclui o tema, a Central, a receita da ISO instalável e o canal de atualizações assinado.

Consulte o [guia de compilação, testes e dual boot](LEIA-ME.md). O workflow **Compilar ISO do danasOS** gera um rascunho em **Releases**. O workflow **Publicar atualização do danasOS** publica um canal APT previamente assinado.
